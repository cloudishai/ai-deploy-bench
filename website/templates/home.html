What does it take for an AI agent to ship your app?

AI Deploy Bench gives an AI coding agent the same five apps to build and deploy on each cloud, from a static site to a realtime chat. Then it measures what it took: whether the app worked, what a person still had to do, how secure it was, how long it took and what it cost.

How a run works

  1. Build

    A fresh Claude Code session builds the app from its spec for the target cloud, without cloud credentials.

  2. Deploy

    The same session gets the cloud's credentials and deploys to a public URL on its own, listing anything only a person could do.

  3. Verify

    Black-box checks test the live app over HTTP and in a browser, and screenshots record what it looks like.

  4. Review

    A separate session scores how securely the app was built and deployed, and whether its hosting plan fits how it's used.

  5. Tear down

    Everything the agent created is priced, then deleted, and the results are committed to the repository.
